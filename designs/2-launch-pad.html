Ports before launch

pick_ports is deterministic: slot n gives 302n / 800n / 543n. The palette can show them before Enter. Needs a launch --dry-run (or the app can compute it from the existing .worktree.env files).

Stages come from the script's own markers

Every ==> line from say() is a stage. Parsing them gives the stepper with no script changes. A traceback inside a stage turns it amber (⚠), not "done".

Every flag gets a control

--backend-base, --frontend-base, --no-start and --refresh-snapshot exist today, but only from a terminal.

Receipt = persisted job summary

Today /api/worktrees returns only running jobs, so after it finishes the summary is gone. Saving the last launch per ticket fixes "I lose the ports".
