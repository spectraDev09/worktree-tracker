1
Ports are the headline, not grey footnotes

Today :3022 is rendered muted next to "Frontend". Here each port is 30px mono with a color per service, so you can find one from across the room.

2
The Postgres port comes back

The script already returns pgPort, but the UI's type drops it. The DB socket copies a ready postgres://admin:admin@localhost:5435/grubbs_db.

3
No more cd … && claude

The launch summary tells you to open a terminal. Instead: buttons for T3 Code, a terminal in the worktree, the editor, and Finder.

4
Logs follow, and the receipt is kept

Logs open in a drawer that keeps tailing, instead of a one-off 200-line modal. "launch receipt" is the saved summary from the last launch, so it survives hide and reload.

5
Start / Stop, not only Restart

A worktree you parked keeps its ports, and one ▶ starts it. This needs a stop <t> command in the script (compose stop + stop_frontend).

✓
Per-service controls live on the service

The six equal-weight buttons per row become ↻ and ■ on each socket. Remove moves into ⋯, away from "Backend log".
