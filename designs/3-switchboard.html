The badge counts fully-up worktrees (today it counts anything with a process). A system notification on launch-done, crash or restart puts the ports in the notification itself, so you have them even if you never look at the app.
It's built from data you already have

Ports come from each worktree's .worktree.env, lit/unlit from lsof -iTCP -sTCP:LISTEN, which the script already uses in port_busy. "Foreign" means a listener on a slot port with no worktree behind it.

Explains the surprises

If a stray next dev sits on :3026, pick_ports silently skips slot 6 and the next worktree gets odd ports. The board shows the squatter, with kill and reveal.
